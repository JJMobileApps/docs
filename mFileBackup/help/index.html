mFileBackup

Turn an old phone into a home server to store and share your files.

mFileBackup turns an Android device into a personal or home backup server, allowing other devices to connect as backup clients.

By repurposing an unused smartphone as a server, you can directly back up and manage your photos, videos, audio files, documents, and more. User accounts and access permissions can also be configured directly on the server device.

Key Features

  • Server & Client Modes: Supports both server and client roles.
  • Photo & Video Backup: Safely back up your media.
  • Custom File Type Backup: Select specific file formats to back up.
  • App Gallery & App Cloud: Access your files directly through the app's gallery and cloud features.
  • Backup Status & Media Scan: Track backup progress and scan media files easily.
  • User Management: Easily set up and manage user credentials.
  • HTTPS Encryption: Secure connections using self-signed certificates.

Premium Features

  • Web Gallery & Web Cloud: Access your media and files via a web browser.
  • External Storage Support: Expand storage capacity using external drives.
  • Share-Only User Accounts: Create dedicated accounts strictly for sharing.
  • Enhanced Security: Device authorization approval and automatic IP blocking upon failed login attempts.
  • Metadata Management: Update, restore, and sync file deletion or creation metadata.

Server Usage Guidelines

  • Network Environment: It is recommended to use the server and client on the same local network (Wi-Fi/LAN).
  • Wired Connection: For maximum stability, a wired LAN connection via a USB hub/adapter is recommended. In Wi-Fi environments, the connection may vary depending on device performance or network conditions.
  • Expandable Storage: Expand your server's storage capacity by connecting an external HDD using an OTG adapter or hard drive docking station.
  • Long-Term Operation: When running as a 24/7 server, please monitor charging status, device temperature, power-saving settings, and network stability.
  • Best Fit: mFileBackup is optimized for personal and home environments. Due to the characteristics of using a smartphone as a server, it is best suited for personal file backups or family photo storage rather than large-scale enterprise use or high-traffic environments.

WARNING

Do not run this server on public or untrusted networks.
