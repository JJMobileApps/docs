Your first time with tallCheck

Add a child → Prepare → Measure → Save

Before measuring height with your phone, set the level origin and complete reference measurements. You can also enter known values directly or read the result display of a digital measuring device from a photo.

01 / PREPARE

Preparation and reference measurements

Set the actual paper or marker size, calibrate the level origin and measure reference points at different known heights.

↗ 02 / MEASURE

Measure height with your phone

Level the phone on top of the head, then tilt it toward the floor marker while keeping the contact point fixed.

↗ 03 / READ A PHOTO

Read height and weight from a photo

Crop the numeric display of a digital height meter or scale. Review and correct the recognized values before applying them.

↗ 04 / KEEP GOING

Find answers

Get help with measurement errors, model downloads, app updates, premium access and backups.

↗

Set up a child and a first record

  1. Add a child on the main screen

    Enter the child’s name, date of birth, sex and other profile details. Each child has their own measurements and growth comparisons.

  2. Select the child and open the entry form

    Enter height and weight directly, measure height or read values from a photo. Check the date and the selected units.

  3. Review the values and save

    Applying a recognized or measured result does not finish saving the record. Check the final values and date on the entry form, then save.

Where are Settings and Help?

Select … at the top right of the main screen. Settings contains measurement options, calibration, growth references and backups. Help shows the installed version, premium status and update check. Older app versions may show a settings gear instead.
