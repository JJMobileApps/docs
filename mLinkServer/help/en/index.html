mLinkServer

Create your own domain or path based links and route them to your target server.

mLinkServer lets you run your own personal link and access server directly from your Android device.

Use mLinkServer to create and manage HTTP, HTTPS, and SFTP routes, control user access, and connect approved devices through a simple mobile interface. It is designed for users who want flexible self-hosted access without relying on a separate cloud server.

HTTP HTTPS SFTP Users Device approval App-to-app tunnel

Key Features

  • Run HTTP, HTTPS, and SFTP server access from your device.
  • Create links using your preferred domain or path instead of relying only on an IP address and port.
  • Create and manage multiple link routing rules.
  • Control access with users, login, and device approval.
  • Manage approved devices and blocked IP addresses.
  • Connect to mFileServer through app-to-app connections, not only by direct IP-based access.
  • Use tunnel-based connections for supported remote targets.
  • View server status and manage settings in one place.
  • Restore server behavior after restart when enabled.
  • Upgrade to Premium for advanced multi-user and multi-link features.

Premium Features

  • Enable Login Required mode.
  • Enable Login + Approval mode.
  • Activate more users.
  • Activate more links.
  • Use advanced access control options.

Designed For Personal Server Management

mLinkServer is built for personal server management, controlled sharing, and secure access to your own resources. It lets you set up links with the domain or path you want, route them to the target server you choose, and connect with mFileServer through supported app-to-app connections. All server operation and most data processing happen on your device, based on the settings you choose.

Google Play in-app purchases are used to unlock Premium features.

Security Note

When exposing access outside your local network, use login, approval, and IP blocking carefully. Review your router, domain, and port forwarding settings before sharing links with others.
