1
Open the Share Action

In the user management list, tap the share icon for the target user to open the web shortcut sharing dialog. This action creates a browser-access shortcut that is tied to that specific user account. The shared link can open the content immediately without requiring the user to enter account information, and it can be used only in the first browser that opens it.

  • The share icon is shown next to the user card.
  • The shortcut is created for the selected user only.
  • Users can view the content directly by opening the shared link.
  • The shortcut becomes bound to the first browser that accesses it.
  • This is useful when you want to give browser access without exposing the full admin flow.
2
Configure the Web Shortcut

This dialog defines how the web shortcut can be opened and how long it remains valid. It also lets you protect the first access with an optional password.

  • Server Address is the browser address that the shortcut will use. If you are using a custom domain or a different address, enter the exact address that users should open.
  • Access Keep Period controls how long the allowed browser can keep access after approval.
  • First-Use Window limits how long the shortcut can wait before its first successful use.
  • Shortcut password (optional) adds a one-time password challenge before the browser becomes the allowed browser.
Tip
How Browser Binding Works

The first browser that opens the shortcut becomes the allowed browser for that shared link. After that, other browsers cannot automatically connect with the same shortcut.

  • If the password is left blank, the first browser can connect immediately.
  • If a password is set, the browser must enter it once before it becomes the allowed browser.
  • This reduces accidental reuse of the same shortcut on multiple browsers.
Note
Actions at the Bottom

The dialog provides three actions to help you verify or cancel the setup before sharing the shortcut.

  • Test Connection checks whether the current settings can reach the server correctly.
  • Cancel closes the dialog without creating or sharing the shortcut.
  • Share generates the web shortcut and opens the system share flow.

Recommended Usage

Use a limited access period and an optional shortcut password when the link is intended for one-time onboarding or temporary remote access. For longer-term browser access, review the security settings together with user permissions before sharing.
