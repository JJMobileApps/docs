Main Screen Guide

1

Start HTTP and SFTP Servers

Check the protocol and port, then use the start buttons to run the server you need.

  • To publish a web link, the HTTP or HTTPS server must be enabled.
  • To publish an SFTP link, the SFTP server must be enabled.
  • If login is required, the HTTP or HTTPS server must be enabled.
2

Access Mode and Device Approval

Set the access mode and manage device approval from this section.

Mode

  • Allow All: There is no restriction on normal link access or connection attempts.
  • Login Required: Users must sign in with an account configured in mLinkServer.
  • Login + Approval: Users must sign in and also be approved by the administrator.

Device Approval

In Login + Approval mode, a requested user must be approved before access is allowed. Link access is judged by user and IP together.

3

Login IP Blocking

Repeated login failures can trigger automatic IP blocking. You can adjust the failure count and block duration to match your environment.

4

Link List

Create and manage the links users will open. Each rule defines the public link and the target server that receives the forwarded request.

5

User Management

Add users for sign-in access and decide which links each user can use.

6

External App Connection

When an external app such as mFileServer requests a connection to this mLinkServer, you can approve or reject it from this section.

Basic Setup Order

  • 1. Check server ports: Make sure the HTTP and SFTP ports do not conflict with other apps.
  • 2. Choose the security mode: For outside access, Login Required or Login + Approval is usually the safer choice.
  • 3. Create users: Add accounts first when you plan to protect links with login.
  • 4. Create links: Set the public domain, path, or SFTP connection name and point it to the target server.
  • 5. Approve devices or browsers: Complete approval when external apps or browser admin access are requested.

Security Note

When you expose the server outside your local network, use login, approval, and IP blocking carefully. Check your port forwarding, domain, and shared secret settings before allowing wider access.
