The numbered markers in the image match the explanation cards below.
1
Server Status

This area shows the current server status. If the status is Stopped, the server is not running yet. Press the play button to start the server with the selected protocol and port.

  • The protocol field lets you choose the connection type, such as HTTP or HTTPS.
  • The port number is the port that client devices will connect to.
  • After you start the server, the status text will change to reflect the running state.
2
Manage Users

This menu is used to manage user accounts. You can create an ID and password for each person who will connect, and you can also assign admin rights or link-specific access permissions when needed.

  • It is recommended to create at least one user before you start sharing access.
  • The (1) shown on the button indicates the current number of registered users.
  • You can fine-tune which links and permissions are allowed for each user later.
3
Web Shortcut Links

This is the main feature for mapping an external access address to an internal server or path. Use this menu to add links and define where incoming requests should be forwarded.

  • You can create links based on a domain, path, or connection name.
  • Access to each registered link can be assigned from the user list.
  • You can decide which users are allowed to use each link.
4
Approve Devices

This security feature limits access to approved devices only. You can open the related management screen from the button, and you can enable or disable the feature with the switch below.

  • Use this when you want to allow access only from trusted devices.
  • It is recommended for public networks or environments exposed to the internet.
  • Even if a user signs in successfully, unapproved devices can still be blocked.
5
IP Access / Block

This security feature automatically blocks an IP address after repeated login failures. When the switch is enabled, you can also configure the failure limit and block duration.

  • Max failed attempts is the number of failed logins allowed before blocking starts.
  • Block duration is the length of the block, and 0 means permanent.
  • This is useful for reducing brute-force login attempts.
Tip
Recommended Setup Order

If you want to start quickly from the main screen, the order below is recommended.

  • Step 1: Create at least one account in Manage Users.
  • Step 2: Review the protocol and port, then start the server.
  • Step 3: Add your routing entries in Web Shortcut Links.
  • Step 4: Enable device approval and IP blocking if you need stronger security.

Security Tip

If you plan to use the server from an external network, it is a good idea to enable both Approve Devices and IP Access / Block. Device approval controls who can connect, while IP blocking helps defend against repeated attack attempts.
