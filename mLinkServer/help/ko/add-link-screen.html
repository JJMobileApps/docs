링크 추가 화면 안내

1

대상

전달된 요청을 실제로 받을 원본 서버 주소를 설정합니다.

  • 연결 방식: 직접 IP/도메인 접속인지, 연결된 외부 앱 대상인지 선택합니다.
  • 프로토콜: 연결하려는 서버에 맞춰 `http`, `https`, `sftp` 중 하나를 고릅니다.
  • IP 주소 / 포트: 실제 대상 호스트와 포트를 입력합니다.
  • 이 기기 IP 사용: 대상 서버가 이 기기에서 실행 중일 때 현재 기기 IP를 자동으로 채웁니다.
  • 연결 테스트: 링크를 저장하기 전에 대상 서버에 도달할 수 있는지 확인합니다.
2

링크

사용자가 이 규칙에 접근할 때 사용할 공개 도메인, 경로, 또는 연결 이름을 설정합니다.

  • 매치 방식: 도메인/호스트 기준인지, 로컬 경로 기준인지 선택합니다.
  • 링크: `cloud.abc.com` 또는 `abc.com/aaa` 같은 공개 주소 조각을 입력합니다.
3

사용자

이 링크 규칙을 사용할 수 있는 사용자를 선택합니다.

  • 모든 사용자: 현재 접근 모드 조건을 만족하는 모든 승인 계정에 허용합니다.
  • 선택한 사용자: 특정 계정으로만 이 규칙 사용을 제한합니다.

저장 전 확인

  • 대상 서버가 선택한 프로토콜과 포트에서 실행 중이며 접근 가능한지 확인하세요.
  • 기존 규칙과 겹치지 않는 링크 값을 선택하세요.
  • 저장하기 전에 어떤 사용자가 이 규칙에 접근할 수 있는지 다시 확인하세요.

라우팅 팁

대상과 링크 개념을 분리해서 생각하면 편합니다. 대상은 실제 원본 서버이고, 링크는 그 대상 서버를 가리키는 공개 도메인, 경로, 또는 연결 이름입니다.
