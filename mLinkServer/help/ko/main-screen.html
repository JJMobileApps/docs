메인 화면 안내

1

HTTP와 SFTP 서버 시작

프로토콜과 포트를 확인한 뒤 필요한 서버 시작 버튼을 눌러 실행합니다.

  • 웹 링크를 공개하려면 HTTP 또는 HTTPS 서버가 켜져 있어야 합니다.
  • SFTP 링크를 공개하려면 SFTP 서버가 켜져 있어야 합니다.
  • 로그인이 필요한 경우에도 HTTP 또는 HTTPS 서버가 켜져 있어야 합니다.
2

접근 모드와 기기 승인

이 영역에서 접근 모드를 바꾸고 기기 승인 상태를 관리합니다.

모드

  • 전체 허용: 일반 링크 접근이나 접속 시도에 제한을 두지 않습니다.
  • 로그인 필요: mLinkServer에 등록된 계정으로 로그인해야 합니다.
  • 로그인 + 승인: 로그인 후 관리자 승인까지 받아야 합니다.

기기 승인

로그인 + 승인 모드에서는 요청한 사용자를 승인해야 접근이 허용됩니다. 링크 접근은 사용자와 IP를 함께 기준으로 판단합니다.

3

로그인 IP 차단

로그인 실패가 반복되면 IP를 자동으로 차단할 수 있습니다. 실패 횟수와 차단 시간을 환경에 맞게 조정하세요.

4

링크 목록

사용자가 열게 될 링크를 만들고 관리합니다. 각 규칙은 공개 링크와 요청을 전달할 대상 서버를 정의합니다.

5

사용자 관리

로그인용 사용자를 추가하고 각 사용자가 사용할 수 있는 링크를 정합니다.

6

외부 앱 연결

mFileServer 같은 외부 앱이 이 mLinkServer에 연결을 요청하면 이 영역에서 승인하거나 거절할 수 있습니다.

기본 설정 순서

  • 1. 서버 포트 확인: HTTP와 SFTP 포트가 다른 앱과 충돌하지 않는지 확인하세요.
  • 2. 보안 모드 선택: 외부 접근을 열 때는 로그인 필요 또는 로그인 + 승인 모드가 보통 더 안전합니다.
  • 3. 사용자 생성: 로그인으로 보호할 계획이라면 먼저 계정을 추가하세요.
  • 4. 링크 생성: 공개 도메인, 경로, 또는 SFTP 연결 이름을 정하고 대상 서버로 연결하세요.
  • 5. 기기 또는 브라우저 승인: 외부 앱 연결이나 브라우저 관리자 접근이 요청되면 승인을 완료하세요.

보안 안내

서버를 로컬 네트워크 밖으로 공개할 때는 로그인, 승인, IP 차단 기능을 신중하게 사용하세요. 더 넓게 공개하기 전에 포트 포워딩, 도메인, 공유 비밀키 설정도 함께 점검하세요.
