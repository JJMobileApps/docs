1
Open the Share Action

In the user management list, tap the share icon for the target user to open the web shortcut sharing dialog. The shortcut is tied to that user account when you save it. Approved browsers can open the shared link without entering account credentials. If you set a shortcut password, each new browser must enter it before approval.

  • The share icon is shown next to the user card.
  • The shortcut is created for the selected user only.
  • Users can view the content directly by opening the shared link.
  • New browsers can be approved within the configured time and browser limit.
  • This is useful when you want to give browser access without exposing the full admin flow.
2
Configure the Web Shortcut

Set the server address, available period, approval time limit, and maximum number of browsers. Enter 0 for any period or browser limit to make it unlimited.

  • Server Address is the browser address that the shortcut will use. If you are using a custom domain or a different address, enter the exact address that users should open.
  • accessCode is generated automatically and cannot be edited. Copy it with the copy icon or generate a new one with the refresh icon on the right. Save / Share saves the code shown here.
  • Available period starts when the first browser is approved. Enter 0 days for unlimited access.
  • Approval time limit starts when the link is created and limits when new browsers can be approved. Enter 0 hours for no time limit.
  • Maximum browsers limits how many browsers can be approved. Enter 0 for no browser limit.
  • Shortcut password (optional) is checked once for each new browser before approval.
Tip
How Browser Approval Works

New browsers can be approved until the approval time limit or maximum browser count is reached. Approved browsers are identified by a secure cookie, regardless of IP address.

  • If the password is blank, a new browser can be approved immediately.
  • If a password is set, each new browser must enter it once before approval.
  • Already approved browsers can continue until the available period ends, even after the approval time limit passes.
Note
Close and Share

Use the X in the upper right to close the dialog, or the buttons at the bottom to test and save the shortcut.

  • X closes the dialog without saving a shortcut.
  • Test Connection checks whether the entered server address can be reached.
  • Save / Share saves the displayed accessCode and opens the system share flow.

Recommended Usage

Use a limited access period and an optional shortcut password when the link is intended for one-time onboarding or temporary remote access. For longer-term browser access, review the security settings together with user permissions before sharing.
