Web Admin Page Guide

1

Configure From a Browser

You can open the admin page in a web browser and manage server settings, link rules, user accounts, and external app connections without using the Android app screen directly.

  • Open the admin page using the server address followed by `/admin`.
  • Use it to add links, review link rules, and manage users from a larger screen.
2

Approved Browsers Only

The web admin page can be opened only from an approved browser session. A browser must go through the approval flow before it is allowed to reach the admin page.

  • Even if the server is reachable on the network, an unapproved browser cannot enter the admin page directly.
  • Approval helps protect the management page from unexpected access attempts.
3

Approval Is Still Required In Allow All Mode

Setting the server access mode to Allow All does not skip the admin page approval process. The admin page always requires its own browser approval step.

  • Allow All removes restrictions for normal link access.
  • The admin page remains protected separately because it controls server configuration.
4

What You Can Manage

The web admin page gives access to the same major management areas shown in the app: server management, link list, user management, and external app connection status.

  • Review current links and add new ones.
  • Check enabled users and update access settings.
  • Monitor approved external app connections.

Recommended Use

  • Use the mobile app first to start the server and approve the browser.
  • Use the web admin page when you want a larger screen for repeated rule and user changes.
  • Sign out from the browser admin page when you finish shared or temporary access sessions.

Security Note

The admin page is more sensitive than normal link access because it can change server behavior. Keep browser approval enabled and review approved devices or browsers whenever you share the server on a wider network.
