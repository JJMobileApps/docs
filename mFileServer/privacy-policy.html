mFileServer Privacy Policy

개인정보처리방침

mFileServer는 Android 기기를 파일 공유 서버처럼 사용할 수 있게 해주는 앱입니다. 이 문서는 앱이 어떤 정보를 처리하는지, 왜 필요한지, 그리고 사용자가 어떤 통제권을 가지는지 설명합니다.

mFileServer는 개발자 운영 서버로 사용자 파일을 일괄 업로드하는 서비스가 아닙니다. 데이터는 사용자의 기기 안에서 처리되거나, 사용자가 직접 활성화한 파일 공유 연결을 통해서만 전송됩니다.

App

mFileServer

Effective Date

August 3, 2026

Main Features

FTP, SFTP, WebDAV file sharing

1. 처리하는 정보

mFileServer는 앱 기능 제공을 위해 다음 정보를 처리할 수 있습니다.

  • 사용자가 선택한 공유 폴더와 그 안의 파일 정보
  • 서버 설정값: 포트, 사용자 ID, 비밀번호, 공유 이름, 프로토콜 선택 정보
  • 네트워크 연결 상태 및 로컬 서버 동작 정보
  • 포그라운드 서비스 및 알림 표시를 위한 상태 정보
  • 오류 진단과 안정성 확인을 위한 내부 로그 또는 실행 정보

2. 정보 이용 목적

  • 사용자가 지정한 폴더를 FTP, SFTP, WebDAV 방식으로 공유하기 위해
  • 서버 시작, 중지, 백그라운드 유지, 재부팅 후 복원 기능을 제공하기 위해
  • 접속 상태와 서버 구성 정보를 화면에 표시하기 위해
  • 오류 대응과 기능 개선을 위해 최소한의 실행 정보를 유지하기 위해

3. 권한 사용 안내

앱은 아래 권한을 기능 제공 목적에 한해 사용할 수 있습니다.

  • 인터넷: 파일 공유 서버 통신 및 클라이언트 연결 처리
  • 모든 파일 접근 권한: 사용자가 선택한 공유 폴더에 접근하기 위해 사용
  • 알림 권한: 서버 실행 상태를 알림으로 표시
  • 포그라운드 서비스 권한: 서버를 백그라운드에서 계속 실행하기 위해 사용
  • 부팅 완료 수신: 사용자가 원할 경우 재부팅 후 서버 상태 복구

4. 정보 저장 및 전송

앱 설정과 실행 상태 정보는 주로 사용자의 기기 안에 저장됩니다. 파일 자체는 사용자가 선택한 저장소 위치에 남아 있으며, 앱이 별도 개발자 서버로 자동 전송하지 않습니다.

사용자가 서버를 실행하면 연결된 클라이언트와의 파일 공유 과정에서 파일 또는 파일 메타데이터가 전송될 수 있습니다. 이 전송은 사용자가 직접 활성화한 네트워크 공유 기능의 일부입니다.

5. 제3자 제공 및 광고

개발자는 사용자의 파일이나 개인정보를 판매하지 않습니다. 이 앱은 제3자 광고 SDK를 포함하지 않으며, 광고 목적의 추적을 수행하지 않습니다.

6. 사용자 선택과 삭제

  • 사용자는 언제든지 서버 실행을 중지할 수 있습니다.
  • 공유 폴더, 포트, 계정 정보 같은 서버 설정은 사용자가 직접 변경하거나 삭제할 수 있습니다.
  • 앱 삭제 또는 앱 데이터 삭제 시 저장된 설정 및 내부 상태 정보가 제거될 수 있습니다.

7. 아동의 개인정보

이 앱은 일반적인 파일 공유 기능을 제공하며, 아동을 대상으로 특별히 설계되지 않았습니다. 보호자는 네트워크 공유 기능 사용 시 적절한 지도와 관리를 제공해야 합니다.

8. 방침 변경

개인정보처리방침은 기능 변경, 법적 요구사항, 배포 정책 변경에 따라 수정될 수 있습니다. 중요한 변경이 있으면 이 페이지의 시행일을 함께 갱신합니다.

9. 문의처

English Summary

mFileServer turns your Android device into a local file sharing server. It may process the folder you choose to share, server configuration values, local network state, notification status, and internal logs needed to keep the service running.

The app mainly operates on your device and only transmits data when you explicitly enable file sharing with connected clients. It does not include third-party advertising SDKs and is not intended to sell personal data.
