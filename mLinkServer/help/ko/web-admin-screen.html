웹 관리자 페이지 안내

1

브라우저에서 설정

웹 브라우저에서 관리자 페이지를 열어 안드로이드 앱 화면에 직접 들어가지 않고도 서버 설정, 링크 규칙, 사용자 계정, 외부 앱 연결을 관리할 수 있습니다.

  • 서버 주소 뒤에 `/admin` 을 붙여 관리자 페이지를 엽니다.
  • 더 큰 화면에서 링크 추가, 규칙 확인, 사용자 관리를 할 때 유용합니다.
2

승인된 브라우저만 접근

웹 관리자 페이지는 승인된 브라우저 세션에서만 열 수 있습니다. 브라우저는 먼저 승인 절차를 거쳐야 관리자 페이지에 들어갈 수 있습니다.

  • 네트워크에서 서버 주소를 알고 있어도 승인되지 않은 브라우저는 바로 들어올 수 없습니다.
  • 승인 절차는 예상치 못한 관리 페이지 접근을 막는 데 도움이 됩니다.
3

전체 허용 모드여도 관리자 승인은 필요

서버 접근 모드를 전체 허용으로 두어도 관리자 페이지 승인 절차는 생략되지 않습니다. 관리자 페이지는 항상 별도의 브라우저 승인 단계를 요구합니다.

  • 전체 허용은 일반 링크 접근 제한만 완화합니다.
  • 관리자 페이지는 서버 설정을 바꿀 수 있기 때문에 별도로 보호됩니다.
4

관리할 수 있는 항목

웹 관리자 페이지에서는 앱에서 보이던 주요 관리 영역을 거의 그대로 다룰 수 있습니다. 서버 관리, 링크 목록, 사용자 관리, 외부 앱 연결 상태를 확인하고 수정할 수 있습니다.

  • 현재 링크를 확인하고 새 링크를 추가할 수 있습니다.
  • 활성 사용자와 접근 설정을 점검하고 수정할 수 있습니다.
  • 승인된 외부 앱 연결 상태를 모니터링할 수 있습니다.

권장 사용 방식

  • 처음에는 모바일 앱에서 서버를 시작하고 브라우저 승인을 완료하세요.
  • 규칙과 사용자 설정을 반복해서 바꿔야 할 때는 웹 관리자 페이지가 더 편합니다.
  • 공용 또는 임시 브라우저에서 작업했다면 관리자 페이지 사용 후 로그아웃하세요.

보안 안내

관리자 페이지는 일반 링크 접근보다 민감합니다. 서버 동작을 바꿀 수 있기 때문입니다. 서버를 더 넓은 네트워크에 공유할 때는 브라우저 승인을 유지하고, 승인된 기기나 브라우저 목록도 주기적으로 확인하세요.
