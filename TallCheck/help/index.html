01 / PREPARE

측정 준비와 기준측정

용지·마커의 실제 크기를 설정하고, 수평 원점과 서로 다른 높이의 기준측정을 준비합니다.

↗ 02 / MEASURE

휴대폰으로 키 측정하기

정수리에서 수평을 맞춘 뒤, 접촉 지점을 유지하며 바닥의 마커를 비춥니다.

↗ 03 / READ A PHOTO

사진에서 키·몸무게 읽기

디지털 키 측정기나 체중계의 숫자 표시창을 잘라 인식하고, 결과를 확인해 적용합니다.

↗ 04 / KEEP GOING

막히는 부분 해결하기

측정 오차, 모델 다운로드, 업데이트, 프리미엄과 백업에 관한 안내를 확인합니다.

↗

아이와 기록을 먼저 준비하세요

  1. 메인 화면에서 아이를 추가합니다

    이름과 생년월일, 성별 등 아이 정보를 입력하세요. 아이별로 측정 기록과 성장 비교를 관리합니다.

  2. 아이를 선택하고 기록 화면을 엽니다

    키와 몸무게를 직접 입력하거나, 키 측정·사진에서 읽기로 값을 가져오세요. 날짜와 단위를 확인합니다.

  3. 값을 확인한 뒤 저장합니다

    인식 결과를 적용하는 단계와 기록을 저장하는 단계는 다릅니다. 등록 화면에서 값과 날짜를 다시 확인하고 저장하세요.

설정과 도움말은 어디에 있나요?

메인 화면 오른쪽 위의 더보기를 누르면 설정과 도움말이 나옵니다. 설정에서는 측정·보정·비교 자료·백업을, 도움말에서는 버전·프리미엄 여부·업데이트 확인을 볼 수 있습니다. 이전 버전에는 설정 톱니바퀴가 표시될 수 있습니다.
