mFileBackup

사용하지 않는 스마트폰을 개인 파일 백업 서버로 활용하세요.

mFileBackup은 안드로이드 기기를 개인 또는 가정용 백업 서버로 사용하고, 다른 기기에서 백업 클라이언트로 연결할 수 있게 합니다.

사진, 동영상, 오디오, 문서 등을 직접 백업하고 관리할 수 있습니다. 서버 기기에서 사용자 계정과 접근 권한도 설정할 수 있습니다.

주요 기능

  • 서버와 클라이언트 모드: 기기를 서버 또는 백업 클라이언트로 사용할 수 있습니다.
  • 사진·동영상 백업: 미디어 파일을 백업합니다.
  • 파일 형식 선택: 백업할 파일 형식을 지정할 수 있습니다.
  • 앱 갤러리와 클라우드: 앱에서 백업한 파일에 접근할 수 있습니다.
  • 백업 상태와 미디어 검색: 진행 상태를 확인하고 미디어를 검색합니다.
  • 사용자 관리: 사용자별 계정과 권한을 설정합니다.
  • HTTPS 연결: 자체 서명 인증서를 이용한 암호화 연결을 지원합니다.

프리미엄 기능

  • 웹 갤러리와 웹 클라우드: 브라우저에서 미디어와 파일에 접근합니다.
  • 외부 저장소: 외장 드라이브로 저장 공간을 확장합니다.
  • 공유 전용 사용자: 공유에 사용할 별도 계정을 만듭니다.
  • 기기 승인: 승인된 기기만 서버에 연결할 수 있게 합니다.
  • 메타데이터 관리: 파일 생성·삭제 정보를 갱신하거나 복원합니다.

서버 사용 안내

  • 네트워크: 서버와 클라이언트를 같은 로컬 네트워크에서 사용하는 것을 권장합니다.
  • 유선 연결: 안정적인 연결이 필요하면 USB 허브나 어댑터를 통한 유선 LAN을 고려하세요.
  • 저장 공간 확장: OTG 어댑터나 도킹 스테이션으로 외장 저장 장치를 연결할 수 있습니다.
  • 장시간 실행: 충전 상태, 기기 온도, 절전 설정, 네트워크 연결을 확인하세요.
  • 권장 용도: 개인 파일 백업이나 가족 사진 보관 등 가정용 환경에 적합합니다.

주의

공용 네트워크나 신뢰할 수 없는 네트워크에서는 서버를 실행하지 마세요.
