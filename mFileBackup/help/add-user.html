1
Basic User Information

Enter the core account information for the new user here. This section defines how the user will appear in the app and how the user will sign in.

  • Display name is the readable name shown in the user list.
  • Username is the login ID the client will use to connect.
  • Password is required for authentication.
  • The Use switch enables or disables the account immediately.
2
Storage Access

This section controls where the user's backup data will be stored. In this screen, the storage mode is set to direct access, and you can also confirm whether full file access has already been granted.

  • Storage Access Mode: Direct means the app uses direct storage access instead of SAF-based folder access.
  • Select Storage Folder opens the folder picker for this user's backup location.
  • All files access shows whether the full storage permission is currently granted.
  • When full file access is granted, backup folders are less restricted and file uploads can work more smoothly.
3
Usage Type

Choose how this user account will be used. Each option is designed for a different backup or sharing scenario.

  • Shared favorites viewer is a view-only type that can open shared favorites only.
  • Back up all photos & videos is the simplest choice for full media backup.
  • Use cloud only limits the account to cloud-focused access.
  • Back up files is suitable when the user needs document or file backup rather than media only.
  • When Back up files is selected, the File-Type Backup Direction options become available.
  • Upload, Download, and Bidirectional let you decide how file sync should work for file-type backups.
4
Feature Access

This section controls which app features the user is allowed to use after the account is created. It helps you create stricter accounts for backup-only or sharing-only use cases.

  • Read-only prevents the user from modifying stored content.
  • Use Gallery allows access to the gallery-related feature set.
  • Allow web access under each feature controls whether the user can use that feature from the web interface.
  • Use Cloud enables access to the cloud-related feature set for this user.
  • Gallery access and Cloud access can be enabled separately, so each user can have a narrower permission set.
Tip
Recommended Setup Flow

If you are creating a normal home backup account, this is the easiest order to follow.

  • Step 1: Enter the display name, username, and password.
  • Step 2: Select the storage folder and confirm that full file access is granted if you plan to use direct access.
  • Step 3: Choose the usage type that matches the user's purpose.
  • Step 4: If you choose Back up files, review the file-type backup direction options as well.
  • Step 5: Enable only the features the user actually needs.
  • Step 6: Tap Add to create the account.
Note
Permission Considerations

Storage-related permissions affect both flexibility and control. Since this screen uses direct storage mode, folder selection and full file access status should be checked together.

  • Direct access can be more flexible, but it depends on storage permission being granted correctly.
  • If file backup behavior is important, review the upload, download, and bidirectional options carefully.
  • For family or shared environments, consider combining limited feature access with read-only mode where appropriate.

Best Practice

For shared or family use, create separate user accounts instead of reusing one account for everyone. This makes it easier to control storage location, feature access, and future permission changes.
