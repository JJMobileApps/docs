앱 원격 관리 안내

다른 기기의 mLinkServer 앱으로 서버를 관리할 수 있습니다. 서버에서 사용하는 화면과 같은 구성으로 링크, SFTP, 사용자와 기기 승인을 관리합니다. 기존 웹 관리자 페이지도 계속 사용할 수 있습니다.

앱 원격 관리 설정웹 관리자 안내

먼저 서버 기기에서 준비하세요

서버 기기는 실제로 링크를 운영하는 기기이고, 관리 기기는 원격으로 조작할 다른 기기입니다. 서버 기기의 mLinkServer에서 웹서버를 시작하고, 사용자 관리에서 사용할 계정의 관리자 권한을 확인하세요. 관리 기기에도 mLinkServer를 설치하고, 서버의 웹서버 주소와 포트로 접속할 수 있어야 합니다. SFTP만 시작한 상태에서는 앱 원격 관리를 연결할 수 없습니다.

앱 원격 관리는 서버 기기의 프리미엄 활성화가 필요합니다.

1

설정에서 원격 관리를 켜세요

관리 기기에서 메뉴 → 설정(Settings)을 열고 서버 원격 관리(Remote management) 토글을 켭니다. 아래의 연결 항목이 표시되면 서버 주소, 관리자 아이디, 비밀번호, 관리 앱 이름을 입력하세요. 앱 이름은 서버에서 승인할 기기를 구분하는 이름입니다.

2

저장 및 연결로 승인을 요청하세요

저장 및 연결(Save and connect)을 누릅니다. 처음 연결하는 관리 앱은 서버의 승인이 필요합니다. 승인 대기 상태에서는 메인 화면에 서버 주소와 미승인(Unapproved) 상태가 표시됩니다.

3

서버 기기에서 관리 앱을 승인하세요

서버 기기의 mLinkServer에서 기기 승인(Device Approval)을 열고 대기(Pending) 목록을 확인하세요. 요청한 관리자 계정과 관리 앱 이름이 맞는지 확인한 다음 승인(Approve)을 누릅니다. 이 화면은 관리 기기가 아닌 서버 기기에서 처리합니다.

4

새로고침 후 서버를 관리하세요

관리 기기의 메인 화면으로 돌아가 새로고침(Refresh)을 누릅니다. 서버 주소 오른쪽이 연결됨(Connected)으로 바뀌고 서버의 최신 설정과 링크 목록이 표시됩니다. 승인 후 비밀번호를 다시 입력할 필요는 없습니다.

연결 후 알아두세요

  • 새로고침은 연결·승인 상태를 확인하고 서버 정보를 다시 읽습니다. 원격 웹서버 재시작은 서버의 웹서버를 재시작하는 별도 작업입니다. 연결되지 않은 상태에서는 재시작할 수 없습니다.
  • 연결안됨(Disconnected)이면 서버의 웹서버 실행 상태, 주소·포트, 네트워크와 포트포워딩을 확인하세요. 서버가 실제로 중지되었다면 서버 기기에서 먼저 시작해야 합니다.
  • HTTPS 인증서 오류가 나면 설정의 인증서 확인 기능으로 서버 주소와 인증서 정보를 확인한 뒤 신뢰 여부를 결정하세요.
  • 원격 모드의 링크와 설정은 연결된 서버의 데이터입니다. 링크 연결 테스트도 서버에서 실행해 결과를 받습니다. 토글을 끄면 관리 기기의 로컬 모드로 돌아갑니다.
  • 아래 화면 이미지는 영문 앱 기준입니다. 실제 주소와 관리자 계정은 사용하는 서버의 정보로 입력하세요.
