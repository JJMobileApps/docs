Remote App Management Guide

Use mLinkServer on another device to manage your server with the same familiar app screens. Manage links, SFTP, users, and device approvals remotely. The existing web admin page remains available.

Set up remote app managementWeb admin guide

Prepare the server device first

The server device runs your links; the management device is the other device you use to control it. Start the web server in mLinkServer on the server device and check that your account has administrator privileges in user management. Install mLinkServer on the management device and make sure it can reach the server web address and port. Running only SFTP is not enough for remote app management.

Remote app management requires Premium to be active on the server device.

1

Enable remote management in Settings

On the management device, open the menu → Settings and enable Remote management. Enter the server address, administrator username, password, and management app name. Choose an app name that identifies this device on the server.

2

Save and connect to request approval

Press Save and connect. A management app connecting for the first time needs approval on the server. The main screen shows the server address with the Unapproved status while you wait.

3

Approve the app on the server device

On the server device, open Device Approval in mLinkServer and check the Pending list. Verify the administrator account and management app name, then press Approve. Perform this step on the server device.

4

Refresh and manage the server

Return to the management device and press Refresh on the main screen. The status beside the server address changes to Connected, and the app loads current server settings and links. You do not need to enter the password again after approval.

After connecting

  • Refresh checks connection and approval status and reloads server information. Restart web server restarts the remote web server. Restart is unavailable while disconnected.
  • For Disconnected, check that the server web service is running and verify its address, port, network, and port forwarding. If the server is stopped, start it on the server device first.
  • For an HTTPS certificate error, use the certificate check in Settings to review the server address and certificate before deciding whether to trust it.
  • Remote mode uses the connected server’s links and settings. Link tests also run on the server and return their results. Turn the Remote management toggle off to return to the management device’s local mode.
  • Screenshots use the English app interface and demonstration data. Enter the address and administrator account for your own server.
