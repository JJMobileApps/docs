주요 기능 사용 순서

사용자 계정을 만든 뒤 웹 갤러리·웹 클라우드를 허용하거나 특정 파일을 다른 사용자와 공유하는 방법을 설명합니다.

웹 갤러리와 웹 클라우드 사용

서버에서 사용자 계정을 만들 때 각 기능의 권한을 설정합니다.

  • 웹 갤러리를 쓰려면 갤러리 사용과 해당 기능의 웹 접근 허용을 켭니다.
  • 웹 클라우드를 쓰려면 클라우드 사용과 해당 기능의 웹 접근 허용을 켭니다.
  • 웹 접근을 끄면 앱에서는 기능을 사용할 수 있어도 브라우저에서는 열 수 없습니다.

특정 파일을 다른 사용자와 공유

공유할 파일을 즐겨찾기에 추가한 다음 대상 사용자에게 그 즐겨찾기를 공유합니다.

  • 먼저 공유할 파일을 즐겨찾기에 추가합니다.
  • 해당 즐겨찾기를 대상 사용자 계정과 공유합니다.
  • 대상 사용자가 백업 기능 없이 공유된 즐겨찾기만 봐야 한다면 계정 생성 시 공유 즐겨찾기 조회 전용 사용 유형을 선택합니다.
