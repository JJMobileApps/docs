mLinkServer Privacy Policy

Privacy Policy

mLinkServer is an Android app that helps users run a personal link, proxy, and remote access server from their own device. This Privacy Policy explains what information the app may access or process, why it is needed, and what control users have.

mLinkServer is not a developer-operated cloud storage or hosting service for collecting user content. Data is mainly processed on the user's device or transmitted only when the user explicitly enables server, link routing, login, or sharing features.
Developer: JJMobileApps. This policy applies to the mLinkServer Android app published by JJMobileApps.

App

mLinkServer

Effective Date

August 12, 2026

Main Features

HTTP, HTTPS, SFTP, link routing, login, approval, and premium purchase

1. Information the App May Access on Your Device

mLinkServer is designed to run on the user's device. The app may access or locally process the following information only to provide the features selected and controlled by the user:

  • Server configuration values such as ports, protocol selection, routing rules, connection names, and security mode settings
  • User account data created inside the app, such as usernames, password hashes, activation status, and permissions
  • Approval and security records such as approved devices, blocked IP addresses, tunnel clients, login attempts, and access grants
  • Target server connection settings entered by the user, such as host, port, protocol, TLS pin, and related route information
  • Local network and connection status information required to run the server and display status to the user
  • Foreground service and notification state needed to keep the server available
  • Internal logs or runtime information used for troubleshooting, security, and app stability

This information is generally controlled by the user on the user's own device and is not treated as data collected by the developer for a separate cloud service.

2. How the Information Is Used

  • To start, stop, restore, and maintain the local server selected by the user
  • To authenticate users and enforce user-selected security modes such as login or device approval
  • To route links, proxy traffic, or tunnel connections according to rules created by the user
  • To show server status, security events, and configuration information in the app
  • To diagnose errors and improve reliability, security, and performance
  • To manage premium purchase state through Google Play Billing when the user chooses to purchase premium features

3. Permissions

The app may request the following permissions only for functionality related to the service it provides:

  • Internet: to communicate with local or remote clients and target servers over the network
  • Network state / Wi-Fi state: to detect network availability and show server connection status
  • Notifications: to show server status while the service is running
  • Foreground service: to keep the server running in the background
  • Boot completed: to restore server state after device restart if the user chooses that behavior

4. Data Storage and Transmission

App settings, local security records, and service state are primarily stored on the user's device.

When the user runs the server, data such as requests, connection metadata, authentication attempts, or routed traffic may be transmitted between the device and connected clients or configured target servers as part of the feature explicitly initiated by the user.

5. Premium Purchases

mLinkServer may offer premium functionality through Google Play in-app purchases. Purchase processing is handled by Google Play.

The app may receive purchase status information from Google Play, such as whether a premium purchase exists or has been restored, in order to unlock premium features. The developer does not receive or store your full payment card information inside the app.

6. Data Retention and Deletion

mLinkServer does not require a developer-hosted user account. Server settings, user records created inside the app, route settings, service state, and related local app data are generally retained on the user's device until the user changes them, clears app data, or uninstalls the app.

Internal logs or temporary security records, if present, are kept locally for app operation and troubleshooting and may be removed when app data is cleared or the app is uninstalled.

7. Sharing with Third Parties

The developer does not sell personal data and does not operate mLinkServer as a data brokerage or advertising resale service.

Data may be transmitted only as part of the server, routing, login, proxy, or sharing connection that the user explicitly enables between the device, connected clients, Google Play purchase services, and target servers chosen by the user.

8. Ads and Tracking

mLinkServer is not intended to track users for personalized advertising purposes and does not include third-party advertising SDKs for personalized ads.

9. User Choices and Deletion

  • Users can stop the server at any time.
  • Users can change or remove routes, users, approvals, and server settings inside the app.
  • Users can remove stored app settings and local records by clearing app data or uninstalling the app.

mLinkServer does not provide a developer-hosted account creation system, so there is no separate online account deletion workflow for this app at this time.

10. Children's Privacy

This app is a general-purpose server and link management tool and is not specifically directed to children. Parents or guardians are responsible for supervising device and network use where appropriate.

11. Changes to This Policy

This Privacy Policy may be updated if app features, legal requirements, or distribution policies change. The effective date at the top of this page will be updated when material changes are made.
