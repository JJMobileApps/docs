Key Feature Workflows

This page explains two common server-side setup flows that are closely related to user registration. Open each section to see how Web Gallery, Web Cloud, and shared favorites should be configured.

These permissions are configured when a user account is created on the server.

  • Enable Use Gallery and Allow web access if the user should open the Web Gallery.
  • Enable Use Cloud and Allow web access if the user should open the Web Cloud.
  • If web access is disabled, the feature may still be available in the app, but it will not open through the browser.

mFileBackup shares specific files with other users by sharing a favorite.

  • Add the files you want to share to a favorite first.
  • Share that favorite with the target user account.
  • If the target account should not use backup features and should only browse shared favorites, set the usage type to Shared favorites viewer when you create the user.
