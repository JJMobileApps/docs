mFileServer Privacy Policy

Privacy Policy

mFileServer is an Android app that helps users run their device as a file sharing server. This Privacy Policy explains what information the app may access or process, why it is needed, and what control users have.

mFileServer is not a cloud storage service operated by the developer for collecting user files. Data is mainly processed on the user's device or transmitted only when the user explicitly enables file sharing with connected clients.

App

mFileServer

Effective Date

August 3, 2026

Main Features

FTP, SFTP, and WebDAV file sharing

1. Information We May Access or Process

mFileServer may access or process the following information to provide its core features:

  • The folder selected by the user for sharing and information about files in that folder
  • Server configuration values such as port, user ID, password, share name, and protocol selection
  • Local network and connection status information required to run the server
  • Foreground service and notification state needed to keep the server available
  • Internal logs or runtime information used for troubleshooting and app stability

2. How the Information Is Used

  • To share a user-selected folder through FTP, SFTP, or WebDAV
  • To start, stop, restore, and maintain the file sharing server in the background
  • To show server status and configuration information in the app
  • To diagnose errors and improve reliability and performance

3. Permissions

The app may request the following permissions only for functionality related to the service it provides:

  • Internet: to communicate with connected clients over the network
  • All files access: to access the folder selected by the user for sharing
  • Notifications: to show server status while the service is running
  • Foreground service: to keep the server running in the background
  • Boot completed: to restore server state after device restart if the user chooses that behavior

4. Data Storage and Transmission

App settings and service state are primarily stored on the user's device. Files remain in the storage location selected by the user.

When the user runs the server, files and related metadata may be transmitted to connected clients as part of the sharing feature explicitly initiated by the user.

5. Sharing with Third Parties

The developer does not sell user files or personal data. The app is not designed to transfer user data to a developer-operated cloud service for advertising or resale.

6. Ads and Tracking

mFileServer does not include third-party advertising SDKs for personalized ads and is not intended to track users for advertising purposes.

7. User Choices and Deletion

  • Users can stop the server at any time.
  • Users can change or remove shared folders and server settings inside the app.
  • Users can remove stored app settings by clearing app data or uninstalling the app.

8. Children's Privacy

This app is a general-purpose file sharing tool and is not specifically directed to children. Parents or guardians are responsible for supervising device and network sharing use where appropriate.

9. Changes to This Policy

This Privacy Policy may be updated if app features, legal requirements, or distribution policies change. The effective date at the top of this page will be updated when material changes are made.

10. Contact

For privacy-related questions, please use the developer contact information shown on the Google Play listing or see the repository at JJMobileApps/mFileServer.
