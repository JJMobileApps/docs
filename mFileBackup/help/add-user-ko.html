이미지에 표시된 번호와 아래 설명의 번호가 서로 대응합니다.
1
기본 사용자 정보

새 사용자의 계정 정보를 입력합니다. 표시 이름은 사용자 목록에 보이는 이름이고, 사용자 이름과 비밀번호는 클라이언트에서 로그인할 때 사용합니다.

  • 표시 이름: 목록에서 계정을 구분하는 이름입니다.
  • 사용자 이름: 클라이언트가 입력할 로그인 ID입니다.
  • 비밀번호: 로그인 인증에 필요합니다.
  • 사용: 계정을 즉시 활성화하거나 비활성화합니다.
2
저장소 접근

사용자 백업 파일을 저장할 위치와 접근 방식을 설정합니다.

  • 직접 접근: SAF 폴더 접근 대신 저장소에 직접 접근합니다.
  • 저장 폴더 선택: 이 사용자의 백업 위치를 지정합니다.
  • 모든 파일 접근: 전체 파일 접근 권한의 허용 상태를 확인합니다.
  • 직접 접근을 쓴다면 폴더와 접근 권한을 함께 확인하세요.
3
사용 유형

계정의 백업 또는 공유 용도를 선택합니다.

  • 공유 즐겨찾기 조회 전용: 공유받은 즐겨찾기만 볼 수 있습니다.
  • 모든 사진·동영상 백업: 미디어 전체를 백업합니다.
  • 클라우드만 사용: 클라우드 중심으로 사용합니다.
  • 파일 백업: 문서 등 파일을 백업합니다.
  • 파일 백업을 고르면 업로드, 다운로드, 양방향 중 동기화 방향을 선택할 수 있습니다.
4
기능 접근 권한

계정을 만든 뒤 사용할 수 있는 기능을 정합니다. 백업 또는 공유 용도에 맞게 필요한 권한만 켜세요.

  • 읽기 전용: 저장된 콘텐츠를 수정하지 못하게 합니다.
  • 갤러리 사용: 갤러리 기능을 허용합니다.
  • 클라우드 사용: 클라우드 기능을 허용합니다.
  • 각 기능의 웹 접근 허용으로 브라우저 접근을 따로 제어할 수 있습니다.
팁
설정 순서
  1. 표시 이름, 사용자 이름, 비밀번호를 입력합니다.
  2. 저장 폴더를 선택하고 필요한 저장소 권한을 확인합니다.
  3. 계정 용도에 맞는 사용 유형을 고릅니다.
  4. 파일 백업을 고른 경우 백업 방향을 확인합니다.
  5. 필요한 기능만 허용하고 추가를 눌러 계정을 만듭니다.
참고
권한 확인

직접 접근 방식에서는 저장 폴더와 전체 파일 접근 권한을 함께 확인하세요. 파일 백업에서는 업로드·다운로드·양방향 옵션도 검토하세요. 가족이나 여러 사람이 사용한다면 계정별로 기능 권한과 읽기 전용 설정을 조정할 수 있습니다.

권장 사항

여러 사람이 사용할 때는 계정을 공유하기보다 사용자별로 별도 계정을 만드세요. 저장 위치와 기능 접근 권한을 개별적으로 관리하기 쉽습니다.
