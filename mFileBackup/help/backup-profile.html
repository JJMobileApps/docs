The numbered markers in the image match the explanation cards below. This screen is divided into three main setup areas: server connection, backup target settings, and backup options.
1
Basic Profile Information

The profile name helps you distinguish one backup profile from another in the client list. Use a name that makes the server or backup purpose easy to recognize later.

  • Profile Name is the label shown in the client profile list.
  • The back button returns to the previous screen without saving recent edits.
  • The check icon at the top right saves the profile.
2
Server Connection Settings

Marker 1 points to the server connection card. This area defines how the client connects to the server and whether the current account can be approved and validated.

  • HTTP / HTTPS selects the protocol used for the connection.
  • Server IP/Domain and Port define the exact server address.
  • Username and Password must match a user created on the server device.
  • Connected reflects the current connection and approval result after a successful check.
  • Refresh checks the server again and reloads approval or capability information.
3
Backup Target Settings

Marker 2 points to the backup target card. This area defines where backup data should go and what kind of backup behavior this profile should use.

  • Remote Folder Path selects the server-side target folder for this profile. It is also used as the folder (album) grouping in the gallery.
  • Usage Type decides the overall backup mode. In this example, it is set to Back up files.
  • Backup Direction is visible because file backup is selected. Here it is set to Upload.
  • Select folders is used to choose the local source folders that will be uploaded.
  • Configure file types defines which file types should be backed up for this profile.
4
Backup Options

Marker 3 points to the backup options card. This area controls how uploads run, how retries are handled, when backups are allowed, and how automatic scheduling works.

  • Simple Upload uploads only changed files after the last successful backup. Deletions and renames are not checked.
  • Reupload deleted server files tries to restore and upload again when the server-side file is already in trash.
  • Backup only on Wi-Fi prevents backup activity on mobile data.
  • Auto Backup turns scheduled backup on or off.
  • Auto Backup Schedule defines the schedule mode. In this example, the interval setup is open.
  • Auto Backup Interval is set to 30 minutes, which is also shown as the minimum allowed interval.
Tip
Recommended Setup Order

The screen is easiest to configure when you move through the cards from top to bottom.

  • Step 1: Enter the profile name.
  • Step 2: Complete the server connection card and confirm the connection result.
  • Step 3: Choose the remote folder and the usage type.
  • Step 4: If file backup is selected, review backup direction, local folders, and file type settings.
  • Step 5: Finish the backup options such as simple upload, Wi-Fi-only behavior, and auto backup.
Note
Why Some Fields Change

This screen is dynamic, so the visible options can change depending on the connected server account and the selected usage type.

  • If the server user allows only certain usage types, the dropdown shows only those allowed choices.
  • Backup Direction, Select folders, and Configure file types can appear or disappear depending on the selected mode.
  • The auto backup area can also change depending on whether interval, daily, weekly, or monthly scheduling is selected.
  • Some options are forced automatically in specific modes, such as simplified upload behavior in full media backup mode.

Best Practice

Save the profile only after the server connection is confirmed and the target settings are reviewed together. This reduces confusion later when multiple profiles point to different users, folders, or backup rules.
