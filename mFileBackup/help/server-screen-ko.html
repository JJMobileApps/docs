사용자 추가 도움말
이미지에 표시된 번호와 아래 설명의 번호가 서로 대응합니다.
1
서버 상태

현재 서버 상태를 표시합니다. Stopped는 서버가 실행 중이지 않다는 뜻입니다. 프로토콜과 포트를 확인한 뒤 재생 버튼을 눌러 서버를 시작할 수 있습니다.

  • 프로토콜에서 HTTP 또는 HTTPS 연결 방식을 선택합니다.
  • 포트 번호는 클라이언트 기기가 연결할 때 사용하는 번호입니다.
  • 서버를 시작하면 상태 표시가 실행 중 상태로 바뀝니다.
2
사용자 관리

서버에 연결할 사용자의 계정을 관리합니다. 사용자별 아이디와 비밀번호를 만들고 필요한 권한을 설정할 수 있습니다.

  • 클라이언트에서 접속하기 전에 사용자를 한 명 이상 만드세요.
  • 버튼의 (1)은 현재 등록된 사용자 수를 뜻합니다.
  • 사용자별 접근 범위와 권한은 계정 설정에서 조정할 수 있습니다.
3
웹 바로가기 링크

사용자에게 공유한 웹 바로가기 링크를 관리합니다. 링크를 받은 사용자는 브라우저에서 해당 계정의 콘텐츠에 접근할 수 있습니다.

  • 공유한 링크를 확인하고 관리할 수 있습니다.
  • 새 링크는 사용자 관리 화면에서 해당 사용자의 공유 기능으로 만듭니다.
  • 설정 방법은 웹 바로가기 공유 도움말을 참고하세요.
4
기기 승인

승인된 기기만 서버에 접속하도록 제한합니다. 버튼으로 승인 기기를 관리하고, 아래 스위치로 기능을 켜거나 끌 수 있습니다.

  • 신뢰할 수 있는 기기만 접속하도록 제한할 때 사용합니다.
  • 외부 네트워크에서 서버에 접속할 계획이라면 사용을 고려하세요.
  • 로그인에 성공해도 승인되지 않은 기기는 접속이 제한될 수 있습니다.
팁
권장 설정 순서
  1. 사용자 관리에서 계정을 한 명 이상 만듭니다.
  2. 프로토콜과 포트를 확인하고 서버를 시작합니다.
  3. 브라우저 접속이 필요하면 웹 바로가기 링크를 사용합니다.
  4. 승인된 기기만 접속하게 하려면 기기 승인을 켭니다.

보안 안내

외부 네트워크에서 서버를 사용한다면 기기 승인을 켜서 승인된 기기의 접속만 허용하는 것을 고려하세요.
